# PROJECT VOICE — Public Explainer

Project / author: Hypothesis Stress Test — публичное объяснение для нетехнической аудитории  
Default mode: fiction (притча, сцена) или general (простое объяснение)  
Audience: обычный человек «на улице»; без опыта в продуктах, IT и AI

Voice: тёплый, ясный, разговорный; как если бы рассказывали знакомому во дворе или за чаем

Preferred rhythm: связные абзацы; короткие фразы — только для удара; без заголовков-конспекта внутри текста

Allowed texture: бытовые детали, диалог, одна запоминающаяся аналогия (горка, мост, список покупок)

Forbidden patterns: backlog, MVP, RAG, JTBD, compliance, governance, strategic fit, «фреймворк», «стресс-тест», «агент», «конвейер»; LinkedIn-пафос; essay-голос; таблицы и нумерованные списки из семи шагов

Must preserve:
- идея звучит разумно, но это не доказательство
- проверка до больших трат (дешёвые вопросы раньше «стройки»)
- разные люди видят проблему по-разному
- противоречия не прячут — они полезны
- хороший исход: «пока не строй, сначала проверь вот это»

Must avoid:
- новые кейсы, цифры, обещания
- tech/product/security jargon
- назначение героя «ИИ» или «системой» — лучше сосед, друг, знакомый с неудобными вопросами

Review checklist:
- [ ] Понятно человеку без IT-фона
- [ ] Есть хотя бы одна живая сцена или аналогия
- [ ] Нет product/AI жаргона
- [ ] Сохранён смысл «проверить раньше, чем тратить»
- [ ] Финал — одна фраза, которую легко пересказать
