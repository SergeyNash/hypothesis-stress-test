# Persona Builds

Файлы persona build документируют, как переиспользуемые персоны были синтезированы из интервью и research-материалов.

Используйте эту папку, когда персона пересобирается по новым CustDev-доказательствам.

## Рекомендуемый формат

```markdown
---
persona: Application Security Engineer
slug: application-security-engineer
built_on: YYYY-MM-DD
source_interviews:
  - interview-001
  - interview-012
confidence: medium
---

# Persona Build: Application Security Engineer

## Source Set

## Repeated Patterns

## Contradictions

## Changes To Persona

## Evidence Gaps
```

## Правило

Persona build должен объяснять, почему персона изменилась, а не только что изменилось.
