# Прогон гипотезы

Используй hst-start для новой гипотезы и hst-run для последовательного выполнения/продолжения. Роли → локальные основания → бизнес-контекст → рынок → синтез → план проверки → критический разбор → human_report.md + human_report.html. Недоступные каналы дают ограничения, а не вымышленные результаты. Все переходы ведёт модель в диалоге, результаты и прогресс — Markdown; итог дополнительно оформляется статическим HTML без сервера и отдельного согласования.
