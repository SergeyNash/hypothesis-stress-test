# Локальные источники

Выбор области в диалоге → короткий список релевантных файлов → чтение доступными инструментами → основания в evidence_inventory.md. Модель сама выбирает материалы по вопросу гипотезы; нет Python-поиска, автоматического ранжирования, snapshot и повторной сериализации фактов.

Содержимое недоступно — явный пробел. Большая обработка — выбор глубины до начала. Имена файлов не являются содержательными доказательствами. Прежние runs и служебные каталоги исключены.
