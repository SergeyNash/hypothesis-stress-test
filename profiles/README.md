# Профили применения

Профиль определяет предмет проверки, нужные данные и критерии решения. Адаптер исполнения (Cline или ручной режим) выбирается независимо.

| Токен | Назначение | Контракт |
|---|---|---|
| `digital_product` | Цифровой продукт, функция, продуктовая инициатива | [digital-product.md](digital-product.md) |
| `service_business` | Услуга, предложение, коммерческая модель, оказание, улучшение, расширение | [service-business.md](service-business.md) |

Без поля `Application Profile / Профиль применения` использовать `digital_product`. Существующие прогоны не требуют миграции. Не выбирать профиль по наличию CIO или CFO: эти роли могут быть релевантны обоим профилям.

Профиль фиксируется во входе до выполнения фаз. При его изменении повторно валидировать вход и считать все прежние фазовые outputs устаревшими. Показать план перезаписи по правилам resume.

Пример сервиса: [example-005](../examples/example-005/run.md). Перечень изменений: [service-business](../roadmap/service-business.md).
