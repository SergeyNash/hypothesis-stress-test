# Roadmap

В 2.11 удалён технический контур оркестрации и машинного аудита. Приоритет — качество диалога и содержательных результатов, ограниченный отбор релевантных источников, краткие планы проверки и пассивный HST Progress Task. Никаких обязательных runtime-схем и зависимости исследования от интерфейса.
