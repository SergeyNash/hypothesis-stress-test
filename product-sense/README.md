# Product Sense — материалы конференции

Материалы для доклада **«Стресс-тест продуктовых гипотез с помощью агентных ИИ-систем»** на Product Sense.

Эти файлы — **конференционные**, не часть core-контрактов фреймворка. Сам фреймворк живёт в `layers/`, `.cline/skills/` и `examples/`.

**Язык:** все материалы в этой папке — на русском.

## Позиционирование для Product Sense

Ведите с **качества продуктового решения**, а не с AI-инструментов или security-домена:

> RAG находит документы. Продуктовой команде нужно снизить неопределённость до попадания идеи в backlog.

Агентный конвейер — это **дисциплина мышления**, а не замена чата.
