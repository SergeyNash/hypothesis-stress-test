# Итоговый отчёт

Создай outputs/human_report.md по содержательным результатам текущего прогона. Никаких HTML-прогресса, серверов, технических валидаторов и JSON.

Отчёт содержит исходную формулировку дословно, рекомендацию и уверенность, важные основания с прямыми ссылками, контраргументы, неизвестное, ограничения и ближайшую проверку. Для сервиса отдельно объясни клиентскую ценность, путь покупки, исполнимость и экономику; не смешивай их в одну оценку.

Не переписывай все документы целиком: краткий вывод и ссылки на детали. Укажи использованные/отключённые/недоступные каналы. Симуляции ролей не выдавай за интервью, синтетические цифры — за факты. Сохраняй периоды, выборки, единицы и условия рекомендаций.

Перед выдачей сама модель проверяет: исходная идея не подменена, цифры и сроки не противоречат текстам, ссылки ведут на существующие результаты, отсутствие данных не названо доказательством. Нет обязательного технического PASS и «10/10» как меры качества.

Обсуди с пользователем реальный следующий выбор. Запиши завершение/время в progress.md. Отдельный визуальный формат можно подготовить только по явному запросу; для завершения прогона он не требуется.
