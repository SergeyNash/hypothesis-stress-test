# Приёмка HST-06

В папке night-service лежит обезличенный сервисный пример с двадцатью основаниями, пятью ролями, полным и фрагментарным чтением Confluence. В product-search сохранён частичный учебный прогон с одним основанием, одной ролью и неизвестным числом интервью. В каждом примере outputs/human_report.html и outputs/human_report.md — образцы результатов.

Из корня репозитория выполните:

```shell
python tests/test_human_report.py
```

Для проверки поведения модели сделайте отдельную копию учебного прогона без двух готовых отчётов и попросите HST выполнить Human Report по материалам этой копии. Укажите путь к папке прогона:

```shell
python tests/test_human_report.py --run PATH_TO_RUN
```

Проверка сверяет имена локальных Markdown-документов, набор ID оснований и цели ссылок в обоих отчётах учебного формата (явные HTML-якоря). Содержательную приёмку проведите по исходному плану и review. В сервисном случае важны перенос метрики на правильную задачу, причина остановки, границы выборки и решения на порогах. Для второго случая проверьте название команды, продуктовые вопросы и пропуски в статистике.
