# Поиск договора по номеру

<a id="decision"></a>

## Гипотеза и решение

Пользователь каталога быстрее найдёт договор по номеру. [Исходная формулировка](../input/hypothesis.md) · [Все материалы](#materials)

Рекомендация — проверить время поиска. Уверенность низкая. Решение владельца ожидается. [План проверки](customer_discovery_plan.md)

<a id="questions"></a>

## Какое решение предстоит команде «Каталог»?

Кому полезен поиск по номеру? Пользователю, который уже знает номер договора. Один эпизод показывает такой способ поиска. Частота задачи и выигрыш во времени неизвестны. [Наблюдение пользователя](#EVID-017)

<a id="action"></a>

## Ближайшее действие

Сравнить время и правильность поиска по названию и номеру на одних заданиях. Если время снизится при сохранении точности, согласовать разработку. [Сравнить способы поиска](customer_discovery_plan.md)
