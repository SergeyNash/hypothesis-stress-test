# Продуктовая стратегия 2025 — Application Security Platform

## Стратегические приоритеты

1. **Выигрывать enterprise AppSec workflows** — конкурировать операционной эффективностью в CI/CD, не generic risk dashboards.
2. **Расширяться в regulated mid-market** — финансы и healthcare с audit-ready governance.
3. **Дифференцироваться vs Appscreener и Checkmarx** через developer experience и queue/workflow automation.

## Целевой покупатель

- Экономический покупатель: **CISO / Head of Application Security**
- Ежедневные пользователи: AppSec engineers, security champions
- Не primary: individual developers как budget owners

## GTM-фокус

- Land с workflow pain (scan pipeline, queue management, policy gates)
- Expand с governance, audit trail, centralized risk reporting
- Избегать позиционирования как «ещё один vulnerability scanner»

## OKR (H1 2025)

- Увеличить enterprise win rate в competitive bake-offs на 15%
- Сократить time-to-value для новых AppSec-команд (< 2 недель до meaningful scan workflow)
- **Не** приоритет: standalone features без связи с buyer-visible outcomes

## Бизнес-модель

- Revenue: platform subscription + scan capacity
- Retention: глубина CI/CD integration и governance features
- Фичи только для daily operators без CISO-visible value — риск upsell, не core driver
