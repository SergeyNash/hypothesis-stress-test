# Продуктовая стратегия 2026 — Talent Platform (РФ)

## Стратегические приоритеты

1. **Выигрывать крупные сделки с HRD** — управляемый контур ИИ, audit trail, локализация ПДн важнее «умного ранжирования»
2. **Ускорять работу рекрутера** без риска автономных кадровых решений (152‑ФЗ ст. 16)
3. **Отличаться от Huntflow AI и Potok** — управляемый ИИ-помощник внутри ATS, а не ранжирование «чёрным ящиком»

## Целевой покупатель

- Покупатель: **HRD / директор по персоналу**
- Пользователи: IT-рекрутеры, руководители направлений
- Барьер согласования: юридический отдел / DPO в крупных сделках

## Выход на рынок

- Вход через боль рекрутера (перегрузка откликов с hh.ru)
- Расширение: аналитика воронки, объяснение по критериям, повторный поиск по собственной базе
- **Избегать** «ИИ заменяет человека» и «автоматический отказ без пересмотра»

## OKR (H1 2026)

- +20% среднего чека в крупном сегменте через модули ИИ с готовым compliance-пакетом (локализация, журнал действий, ручная корректировка)
- −25% времени рекрутера на первичный отбор в пилотах на IT-вакансиях
- **Не** приоритет: обещание скорости без audit trail и объяснимости для кандидата

## Бизнес-модель

- ATS по числу мест + допродажа модуля ИИ
- Удержание: интеграции с hh.ru / Habr Career, on-prem/private cloud для чувствительных данных
- Задержка согласования с DPO/юристами = задержка выручки

## Рыночный контекст (РФ)

- 37% российских компаний уже используют ИИ в HR-задачах, но только ~5% — в рабочем контуре найма
- Рынок ценит экономию времени рекрутера сильнее, чем «улучшение качества решения»
- Лучшая окупаемость: разбор резюме, повторный поиск по базе, рассылки, планирование интервью — не полностью автоматический отказ
