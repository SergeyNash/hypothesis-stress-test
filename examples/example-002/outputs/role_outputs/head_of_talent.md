# Ролевой анализ: HRD / директор по персоналу

## Боль

Приоритет: СРЕДНИЙ

- Давление руководства по срокам закрытия дефицитных IT-ролей при исторически низкой безработице
- Проверка со стороны юристов и DPO автоматизированного скрининга (152‑ФЗ ст. 16, локализация ПДн)
- Функции вендора с непрозрачной оценкой тормозят закупку

## Новые проблемы

- ИИ-ранжирование без audit trail и объяснения по критериям — барьер для внедрения в крупных компаниях
- Репутационный риск при претензиях кандидата на необоснованный отказ (ТК РФ ст. 64)
- Зависимость от внешних job-сайтов вместо повторного поиска по собственной базе

## Альтернативы

- Отложить ИИ до согласования с DPO и юристами
- Точечные решения с зафиксированными критериями, ручной корректировкой и on-prem/private cloud
- Оставить первичный отбор ручным, нанять младших сорсеров

## Границы применимости

- Работает: управляемый ИИ-помощник с журналом действий, ручной корректировкой, локализацией данных
- Ломается: ранжирование «чёрным ящиком» как «быстрый найм»; полностью автоматический отказ без пересмотра
