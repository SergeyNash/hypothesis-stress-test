# Ролевой анализ: IT-рекрутер

## Боль

Приоритет: КРИТИЧЕСКИЙ

- 3–4 часа на IT-вакансию только на открытие резюме с hh.ru, которые уже явно не подходят
- Давление техлидов за короткий список до завершения разбора откликов
- Страх пропустить сильного кандидата в объёме 200+ откликов

## Новые проблемы

- Автоматическое ранжирование без прозрачности подрывает доверие техлидов
- Объяснение решений ИИ руководителю направления — новая нагрузка
- Ручная корректировка в плохом интерфейсе дублирует работу
- «Адверсариальные» резюме и внедрение инструкций в промпт при LLM-скрининге (растущий риск на российском рынке)

## Альтернативы

- Фильтры по ключевым словам в ATS (Huntflow / Potok)
- Таблица для кандидатов «на рассмотрении»
- Повторный поиск по собственной базе вручную
- Внешние агентства для senior/niche IT-ролей

## Границы применимости

- Работает: массовые IT-вакансии, чёткие обязательные требования, рекрутер сохраняет финальную сортировку
- Ломается: непрозрачный автоматический отказ; поиск топ-позиций с &lt;20 откликами
