# Ролевой анализ: Recruiter

## Боль

Приоритет: CRITICAL

- 3–4 часа на роль только на открытие резюме, которые уже явно не подходят
- Давление hiring managers за shortlist до завершения triage
- Страх пропустить сильного кандидата в объёме

## Новые проблемы

- Auto-ranking без transparency подрывает доверие
- Объяснение ИИ-решений hiring managers — новая нагрузка
- Override workflows могут дублировать работу при плохом UI

## Альтернативы

- Keyword filters в ATS
- Spreadsheet для «maybe» кандидатов
- External agencies для senior roles

## Границы применимости

- Работает: high-volume, чёткие требования, recruiter сохраняет final sort control
- Ломается: opaque auto-reject; executive search с &lt;20 откликами
