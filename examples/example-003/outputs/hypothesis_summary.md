# Резюме гипотезы

## Формулировка

Если добавить в корпоративную базу знаний поиск с помощью искусственного интеллекта, сотрудники будут быстрее находить нужную информацию, реже обращаться к коллегам с вопросами и смогут быстрее выполнять рабочие задачи.

## Скрытые допущения

- Проблема в основном в качестве поиска, а не в актуальности и дублях документов
- Нужная информация уже есть в Wiki в пригодном виде
- Сотрудники доверят ответам ИИ без ссылок на источник
- Меньше вопросов в чате автоматически даст рост эффективности команды
- Сокращение времени поиска измеримо и связано с метриками задач

## Конфликты ролей

- **Разработчик vs владелец базы знаний:** скорость ответа vs ссылки, доступы, журнал запросов
- **Аналитик vs техписатель:** сводка «из коробки» vs ответственность за актуальность страниц
- **Руководитель команды vs пользователи:** меньше отвлечений vs риск неверных ответов ИИ

## Ключевые риски

- Позиционирование «ИИ заменяет Wiki» без контура управления
- Локальная выгода для пользователей без ценности для покупателя (владельца базы)
- Усиление распространения устаревших знаний через уверенные ответы

## Оценка

**Требуется валидация** — боль поиска реальна, но связка «ИИ-поиск → меньше вопросов коллегам → быстрее задачи» опережает evidence. Сильная возможность переформулировки на поиск-помощник с источниками и петлёй для техписателей.
