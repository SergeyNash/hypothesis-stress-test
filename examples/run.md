# Пример организации прогона

input/hypothesis.md — карточка. run.md — согласованные источники, объём и решения. progress.md — короткая заметка о текущей работе. outputs/ содержит Markdown ролевого разбора, локальных оснований, бизнес-контекста, рынка, синтеза, плана проверки, критического разбора и итогового отчёта.

Иллюстративные examples показывают содержание и ограничения, а не обязательную процедуру запуска. Для новой пользовательской гипотезы не читать старые результаты как образцы. Использовать актуальные templates и навыки. Исторические примеры могут иметь иной объём и не являются доказательствами реального спроса.
