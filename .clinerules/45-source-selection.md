# Источники через диалог

До сбора выясни, какие каналы разрешены: локальные материалы, Confluence, интернет. Уже явный выбор не спрашивай повторно. Для локальной БЗ согласуй всю базу или конкретные папки. Сохрани ответ обычным текстом в run.md; прежнее предпочтение не является согласием для нового запуска.

Отключённый канал не вызывается. Инструкции фреймворка и исходная карточка доступны независимо от локальной БЗ. В разрешённой БЗ исключай runs, .hst, .cline/.clinerules, копию фреймворка, зависимости и служебные каталоги. Не читай чужие результаты как материалы клиента.

Модель сама ищет файлы доступными инструментами и объясняет отбор. Сначала краткий список наиболее релевантных документов по задаче; затем чтение выбранного содержания. Не требуются Python discovery, snapshot, source registration или отдельное разрешение через CLI. Список имён ещё не означает прочитанные документы.

Перед тяжёлой обработкой или большим объёмом уточни быстро/подробно/пропустить. В быстром режиме читай ограниченную релевантную часть и обозначай неполноту. При недоступном формате/доступе/канале сообщи фактическое ограничение. Если всё отключено — сделай ограниченный разбор входной гипотезы с явными gaps, не изображай проведённое исследование.
