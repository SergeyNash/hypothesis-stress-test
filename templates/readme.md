# Шаблоны

Шаблоны помогают модели сформировать содержательный Markdown-результат этапа. Используй относящийся к текущей работе файл, не загружай все шаблоны заранее. Масштабируй подробность по задаче: не создавай огромные документы только ради заполнения секций.

- input-schema.md — карточка гипотезы;
- facilitator-prompt.md — ролевой разбор;
- knowledge-retrieval-prompt.md — локальные основания;
- business-context-prompt.md — бизнес-контекст;
- market-prompt.md — рынок;
- synthesis-prompt.md — сопоставление;
- customer-discovery-planning-prompt.md — ближайшие проверки;
- decision-review-prompt.md — критический разбор;
- human-report-template.md — текстовая версия итога;
- human-report-template.html — обязательный итоговый HTML-отчёт, статический и без сервера.

Источники и ограничения описываются непосредственно в результатах. Машинных реестров и исполняемых контрактов нет.
