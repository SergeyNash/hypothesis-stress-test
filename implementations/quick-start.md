# Быстрый старт

1. Открой DataB в VS Code. Установи Cline и настрой свою модель.
2. Помести фреймворк во вложенную папку hypothesis-stress-test-main.
3. Из DataB выполни `python .\hypothesis-stress-test-main\scripts\setup_workspace.py --workspace . --terminal` для проверки плана, затем ту же команду с `--apply --replace-framework-files` для применения.
4. Перезагрузи окно VS Code. Проверь Workspace Rules/Skills и начни новый чат Cline.
5. Напиши гипотезу и попроси полный разбор. Источники и глубину согласуйте в диалоге.
6. Для просмотра открой Terminal → Run Task → HST · Прогресс. Не нужно запускать сервер или отдельный клиент.

[Команды обновления и первый переход с 2.10](../README.md#переход-с-210-и-прежних-версий). Старый updater ожидает файл, который удалён в лёгкой версии: первый переход выполняется новым обновлятором с main. После перехода используется обычная .hst/update.py.

В старой установке удали расширение HST Pipeline Bridge через Extensions → Uninstall и перезагрузи окно VS Code. Setup убирает его известные настройки из активной папки, сохраняя backup. Исторические runs не удаляются.
