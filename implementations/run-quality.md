# Качество содержательного разбора

Проверку делает языковая модель по .clinerules/40-run-quality.md. Сохраняй точные цитаты/места в источниках, контекст чисел и ограничения. Разделяй факты, интерпретации, предложения и неизвестное; проверяй контраргументы и независимость оснований.

Не нужен отдельный файл отчёта о формальной проверке. Существенные проблемы отражаются в самом аналитическом документе и обсуждаются в чате. Итог не получает технический PASS: исследование может быть завершено при высокой неопределённости и необходимости дальнейшей проверки. Завершение работы не равно доказанности гипотезы.
